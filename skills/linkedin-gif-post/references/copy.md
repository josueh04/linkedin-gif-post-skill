# The caption

The graphic stops the scroll. The caption decides whether the reader wants the resource. LinkedIn shows about the first 210 characters before "...see more", and that preview has to sell the click.

## Structure

1. **Line 1: the reader's problem or stake, in plain words.** Name the tool or topic, and make a claim about the reader's world. "Your AI coding pipeline can pass its own tests and still rot your codebase." beats "The cost of generating code collapsed.", which is true but abstract. Never spend the preview on who quoted whom.
2. **The thesis in one or two short sentences,** with the source named once.
3. **The proof as a short list,** one number per line, each with what it means. If the resource has few numbers, use its strongest concrete facts: counts, named steps, a short quote. Do not stack five numbers in one sentence. Define any jargon ("fair teams", "merge yield") or drop it.
4. **The method as a numbered list** that mirrors the cards in the GIF, in the same order. Lead-magnet captions with a numbered list drew 1.53x their author's usual comments.
5. **The scoring rule or the one insight,** in one line ("Fewer than 11 yes means...").
6. **What the resource contains, then the call to action** (see the two modes below).

**Length:** a research post can run 200 to 260 words. That is longer than a typical lead-magnet post, because the reader needs the method to trust the document. Cut anything that does not serve steps 1 to 6.

**Voice:** first person is fine ("before I let a pipeline near a backlog, I..."). Make no claims about results the author did not get, and use no invented numbers.

## Two CTA modes

| | Link in the post | Comment to get it |
|---|---|---|
| Caption ends with | "All 14 checks, with how to score each one:" plus the link on its own line | A short access line pointing at the image: "Free Access 👇", "Get free access 👇", "PRIORITY ACCESS 👇". Never ask for a comment in the caption and never write the keyword there; the image's band does that job |
| CTA band | `FULL DOCUMENT · LINK IN THE POST` | `COMMENT "KEYWORD"` |
| Work after posting | None | Someone has to DM every commenter, by hand or with an automation tool |
| What it buys | Readers get the resource with one click. The tradeoff is that they leave LinkedIn and few comment | Comments signal the algorithm and start a conversation. In the study, comment-gated posts drew 1.5 to 4.8x more comments than reactions |

Why the caption never says "comment": a caption that asks for comments outright ("Comment X and I'll send it") reads as engagement bait to readers and to LinkedIn, and it sounds like a funnel. The access line keeps the caption about the resource and lets the image carry the mechanic.

Start with the link mode if nobody can answer DMs. Move to the comment mode once the content proves itself and someone can handle the replies. Put the keyword only in the image: posts that also put it in the caption drew 0.86x their author's usual comments, against 1.23x when it lived only in the media.

## Worked example (comment mode)

A post for a free playbook, paired with a radar-style GIF (the first graphic in the repository README). Line 1 names the tool and the outcome, the arrows list the six outputs that the GIF's cards show, and the keyword lives only in the image.

```text
One hour a week with Opus 5.5 gets you 6 pieces of client content.

→ a pain map of what your buyer is talking about this month
→ one LinkedIn post built to start conversations
→ a graphic brief
→ a DM that reads like you typed it
→ a newsletter email
→ a blog post and a web section

All from one Claude Project that knows your offer and your voice.

Why Opus 5.5 and not the model you already use:
It shipped on September 22 and costs 40 percent less to run than Opus 5.
Anthropic says it puts the most important information up front.
That is exactly what a LinkedIn hook needs.

I wrote down the whole routine:
Monday research, Tuesday write, Thursday repurpose, Friday read the replies.
Every prompt copy-paste ready.

Get free access 👇
```

The closing "Get free access 👇" is fine in a caption: the no-bait rule is for the image's CTA band, where LinkedIn reads the picture as engagement bait.

Posted as an animated GIF in place of a static photo, it drew about twice the comments per 1k followers of the static version (`evidence.md`).

## Before you post, check

- Can a stranger tell from the first two lines what they get and why it matters to them?
- Does every number have a source the reader could find?
- Does the list in the caption match the cards in the GIF, in order?
- Is the jargon either defined or gone?
- Does the CTA band match the CTA mode of the caption?
